## ExileAppraiser 能幫你做什麼

ExileAppraiser（流亡鑑價）是 Path of Exile 1 / 2 的遊戲內查價工具。玩的時候把滑鼠移到物品上按個熱鍵，交易站的查價結果就會直接跳在游標旁邊，不用切出去開網頁。

- PoE1 跟 PoE2 都能用，會看你前景是哪個遊戲自動切換。
- 國際服跟台服的交易站都能查，繁中跟英文客戶端複製出來的物品文字都看得懂。
- PoE2 另外會讀畫面，靈魂之井三選一跟符文塑形面板旁邊會直接標出詞綴 Tier 跟參考價。
- 不用登入，也不用 POESESSID，查詢都是匿名送到官方交易站跟 poe.ninja。

目前只支援 Windows。

## 下載跟安裝

到 [Releases 最新版](https://github.com/Hsiung-Shao/exile-appraiser/releases/latest) 下載：

| 檔案 | 用途 |
|---|---|
| `ExileAppraiser-Setup-<版本>.exe` | **安裝版，建議下載這個。** 預設只裝給目前的使用者，不需要系統管理員權限。只有安裝版會自動更新 |
| `ExileAppraiser-<版本>-portable.exe` | 免安裝版，點兩下就能開。不會自動更新，有新版的時候「設定 › 關於」會提醒你 |

同一頁的 `.blockmap` 跟 `latest.yml` 是自動更新在用的，不用下載。

程式沒有程式碼簽章，第一次開可能會跳「Windows 已保護您的電腦」。確定檔案是從上面的 Releases 頁下載的，點「其他資訊」→「仍要執行」就可以了。

安裝版會在背景下載新版，你關掉程式的時候才套用，之後只會下載有改到的部分。不想自動更新的話，到「設定 › 關於」關掉。

## 使用方式：第一次設定

程式開起來之後是在背景跑，沒有主視窗。螢幕右下角會短暫跳出「已在背景執行」跟查價熱鍵，程式圖示在工作列右下角的系統匣。

要開設定有三種方法：系統匣圖示按右鍵 →「設定」、遊戲裡沒開查價面板的時候按 `Shift + Space`，或是按查價面板標題列的齒輪。

在「設定 › 一般」照順序確認：

1. **介面語言**：程式本身要顯示繁體中文還是 English。
2. **遊戲**：PoE1 / PoE2，預設會看遊戲視窗自動切。
3. **伺服器**：國際服或台服。台服目前只支援繁中客戶端。
4. **客戶端語言**：你的遊戲是繁中還是英文。國際服查價會自己看複製出來的文字判斷，這裡只是預設值；台服就一律照這個設定，選錯會解析失敗。
5. **聯盟**：選你要查價的聯盟。清單跑不出來就按「開啟交易站(解除驗證)」，在跳出來的視窗過一次 Cloudflare 驗證。

設定改完會自動存，不用另外按儲存。

![設定 › 一般](/images/guides/exile-appraiser/settings-general.png)

*介面語言、遊戲、伺服器、客戶端語言跟聯盟都在「一般」這一頁。*

## 使用方式：查價

| 熱鍵 | 預設 | 作用 |
|---|---|---|
| 快速查價 | `Ctrl + D` | 按住 `Ctrl` 再按 `D`，面板會出現在游標旁邊。`Ctrl` 先不要放，把滑鼠移進面板就能操作；放開 `Ctrl` 再把滑鼠移走，面板就自己關掉 |
| 鎖定查價 | `Ctrl + Alt + D` | 面板可以直接點，滑鼠移開也不會關，適合慢慢調篩選 |
| 設定選單 | `Shift + Space` | 在遊戲跟 overlay 之間切換；沒開查價面板的時候會打開設定 |

熱鍵都可以在「設定 › 熱鍵與視窗」改：點一下欄位，直接按你要的組合鍵，`Esc` 或 `Backspace` 是清除。

1. 遊戲在前景的時候，滑鼠移到物品上按查價熱鍵。程式會幫你送複製鍵：PoE1 是 `Ctrl + C`，PoE2 是 `Ctrl + Alt + C`（要用進階複製才拿得到褻瀆詞綴的 Tier）。
2. 面板會列出這件物品的詞綴，勾你要拿來搜的、調一下數值範圍。預設的容差在「設定 › 查價」。
3. 傳奇跟通貨會直接開始查；其他物品調好篩選之後按「搜尋」。
4. 想看完整結果的話，按「交易」會用瀏覽器打開交易站的同一個搜尋。

也可以手動貼：面板沒有物品的時候，把遊戲裡複製的物品文字貼進去按「解析」。

查價出錯的時候，按面板下面的「回報這件」，程式會幫你整理成 GitHub issue 草稿。它不會自己送出，也不會帶你的帳號名，你看過沒問題再自己送。

![設定 › 熱鍵與視窗](/images/guides/exile-appraiser/settings-hotkeys.png)

*熱鍵、OCR 狀態跟辨識區域都在「熱鍵與視窗」這一頁。*

## 靈魂之井三選一辨識（PoE2）

靈魂之井的揭露面板沒辦法複製文字，所以改用 Windows 內建的文字辨識（OCR）去讀畫面。辨識是在你電腦上跑的，截圖不會存檔也不會上傳。

要先裝 Windows 的 OCR 語言包，裝一次就好：

1. Windows 設定 → 時間與語言 → 語言與地區。
2. 在「中文(台灣)」點「⋯ → 語言選項」；英文客戶端就改選「英文(美國)」。清單裡沒有的話先新增語言。
3. 在「光學字元辨識」按下載。
4. 回到程式的「設定 › 熱鍵與視窗」，「OCR 狀態」顯示「可用」就好了。

之後打開靈魂之井三選一的畫面，每個選項右邊會出現「Tier · 詞綴池 · 數值範圍」的標記。`Ctrl + Shift + R` 可以暫停或繼續自動辨識。

如果標記出現「?」，代表最近 10 分鐘內你沒查過這件物品的價，程式不知道底材是什麼，只能用三個選項都可能出現的底材去推。先對物品查一次價再開面板，結果會準很多。

![靈魂之井辨識標記](/images/guides/exile-appraiser/well-of-souls-ocr.png)

*每個選項右邊會標出詞綴 Tier、詞綴池跟數值範圍。*

辨識不太穩的話，可以在「設定 › 熱鍵與視窗」按「在遊戲上框選」，把揭露面板框起來按 `Enter`。之後它會先只看那一塊，比較快也比較準。

## 符文塑形自動查價（PoE2）

在「設定 › 熱鍵與視窗」勾「啟用符文塑形自動查價」，預設是關的。開著符文塑形面板的時候，程式會定時去讀面板，在每一列右邊標 poe.ninja 的參考價。它只截圖加本機 OCR，不會對遊戲送任何按鍵。

- 用崇高石計價，滿 1 神聖石就改用神聖石；總價高過門檻顯示金色，低於門檻顯示暗色，門檻可以自己在設定裡改。
- poe.ninja 沒有價格的列（像技能寶石）會自動排隊去查交易站，顯示成「市 …」。為了不卡到你平常查價，交易站額度不夠的時候會自動往後延。
- 台服沒有 poe.ninja 價格，所以全部改查台服交易站，用掛單的原幣顯示。

![符文塑形自動查價](/images/guides/exile-appraiser/runeshape-prices.png)

*每一列右邊標參考價，去交易站查到的會另外標「市」。*

## 其他好用的功能

- **Poe Regex 搜尋字串產生器**（設定 › 正則）：選遊戲跟清單，勾你想找的詞綴或名稱，按「複製」貼到遊戲的倉庫或商店搜尋列。可以把好幾頁的勾選合在一起、存書籤、用分享碼給朋友，也有內建範本，像 T17 危險詞綴、地圖無反射。輸出語言要跟你的遊戲客戶端一樣。
- **拆粉排行**（PoE1）：查傳奇的時候面板會告訴你能拆出多少粉塵。「拆粉排行」那一頁列出所有傳奇，可以照「粉塵 / c」「粉塵 / gold」這些排序。價格是 poe.ninja 的，所以只有國際服有。
- **聊天指令跟倉庫搜尋**（設定 › 聊天指令）：預設 `F5` 是 `/hideout`、`F9` 是 `/exit`，`@last ty` 這種也能自己綁熱鍵；倉庫搜尋熱鍵會把字串打進倉庫的搜尋框。
- **用瀏覽器改設定**：系統匣選單的「在瀏覽器開啟設定」可以用一般瀏覽器看設定、改設定，只有你自己這台電腦開得起來。

![拆粉排行](/images/guides/exile-appraiser/dust-ranking.png)

*拆粉排行可以照粉塵效率排，每一列都能直接開交易站或 poe.ninja。*

## 常見問題

### 按熱鍵沒反應，overlay 沒出現在遊戲上

遊戲請用無邊框視窗或視窗模式，全螢幕獨占的話 overlay 可能蓋不上去，OCR 也可能只抓到黑畫面。再看一下「設定 › 熱鍵與視窗」裡的遊戲視窗標題跟實際的一不一樣（預設是 `Path of Exile` / `Path of Exile 2`）。熱鍵被別的程式佔走的時候設定頁會提醒你，換一組就好。不想用 overlay 的話，可以取消「疊加在遊戲上」改成獨立視窗。

### 聯盟清單跑不出來，或是出現驗證頁

交易站前面有 Cloudflare 防護。到「設定 › 一般」按「開啟交易站(解除驗證)」，過完一次驗證再按「重試」。如果顯示「限流中」，那是交易站的查詢頻率限制，倒數完會自己重試。

### OCR 認不出來或找不到面板

先確認「OCR 狀態」是「可用」，缺語言包就照上面的步驟裝。遊戲 UI 太暗也會影響辨識；用框選把範圍縮到面板上通常會比較準，換解析度或 UI 縮放之後要重新框。「辨識語言」要跟遊戲畫面實際的語言一樣。

### 台服跟國際服有什麼不一樣

台服查的是 `pathofexile.tw`，目前只支援繁中客戶端。poe.ninja 沒有台服的價格，所以台服沒有拆粉價格，符文塑形也改成查台服交易站。

### 設定跟記錄存在哪

設定在 `%APPDATA%\exile-appraiser\config.json`，系統匣選單的「開啟設定資料夾」可以直接打開。程式記錄只存在你的電腦，保留 7 天，不會自動上傳；要回報問題的時候可以到「設定 › 記錄」篩出錯誤再複製貼上。
