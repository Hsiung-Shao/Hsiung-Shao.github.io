## ExileAppraiser 是什麼

ExileAppraiser（流亡鑑價）是 Path of Exile 1 / 2 的遊戲內查價工具。在遊戲裡把滑鼠移到物品上按熱鍵，官方交易站的查價結果會直接出現在游標旁邊。

- PoE1 和 PoE2 都能用，會依前景的遊戲視窗自動切換。
- 國際服和台服的交易站都能查，繁體中文和英文客戶端的物品文字都能解析。
- PoE2 另外會用畫面辨識讀靈魂之井三選一和符文塑形面板，直接標出詞綴 Tier 和參考價。
- 不需要登入，也不需要 POESESSID，查詢是匿名送到官方交易站和 poe.ninja。

只支援 Windows。

## 下載與安裝

到 [Releases 最新版](https://github.com/Hsiung-Shao/exile-appraiser/releases/latest) 下載：

| 檔案 | 用途 |
|---|---|
| `ExileAppraiser-Setup-<版本>.exe` | **安裝版，建議下載。** 預設只裝給目前的使用者，不需要系統管理員權限。只有安裝版會自動更新 |
| `ExileAppraiser-<版本>-portable.exe` | 免安裝版，雙擊就能執行。不會自動更新，有新版時「設定 › 關於」會提示 |

同一頁的 `.blockmap` 和 `latest.yml` 是自動更新用的，不用下載。

程式沒有程式碼簽章，第一次執行可能跳出「Windows 已保護您的電腦」。確認檔案是從上面的 Releases 頁下載的，點「其他資訊」→「仍要執行」即可。

安裝版會在背景下載新版，結束程式時套用，之後只下載有變動的部分。不想自動更新可以在「設定 › 關於」關掉。

## 使用方式：第一次設定

程式啟動後在背景執行，沒有主視窗。螢幕右下角會短暫顯示「已在背景執行」和查價熱鍵，程式圖示在工作列右下角的系統匣。

開設定的三種方式：系統匣圖示右鍵 →「設定」、遊戲中沒開查價面板時按 `Shift + Space`、或按查價面板標題列的齒輪。

在「設定 › 一般」依序確認：

1. **介面語言**：程式本身顯示繁體中文或 English。
2. **遊戲**：PoE1 / PoE2，預設會依遊戲視窗自動切換。
3. **伺服器**：國際服或台服。台服目前只支援繁體中文客戶端。
4. **客戶端語言**：你的遊戲是繁中還是英文。國際服查價會自動依複製出來的文字判斷，這裡只是預設值；台服一律照這個設定，選錯會解析失敗。
5. **聯盟**：選要查價的聯盟。清單載不出來就按「開啟交易站(解除驗證)」，在跳出的視窗完成一次 Cloudflare 驗證。

設定改了會自動儲存。

![設定 › 一般](/images/guides/exile-appraiser/settings-general.png)

*介面語言、遊戲、伺服器、客戶端語言與聯盟都在「一般」分頁。*

## 使用方式：查價

| 熱鍵 | 預設 | 作用 |
|---|---|---|
| 快速查價 | `Ctrl + D` | 按住 `Ctrl` 再按 `D`，面板出現在游標旁。繼續按住 `Ctrl` 把滑鼠移進面板就能操作；放開 `Ctrl` 再移開滑鼠，面板會自動關掉 |
| 鎖定查價 | `Ctrl + Alt + D` | 面板可以直接點，不會因為移動滑鼠而關掉，適合慢慢調篩選 |
| 設定選單 | `Shift + Space` | 在遊戲和 overlay 之間切換焦點；沒開查價面板時會打開設定 |

熱鍵都能在「設定 › 熱鍵與視窗」改：點一下欄位直接按新的組合鍵，`Esc` 或 `Backspace` 清除。

1. 遊戲在前景時，滑鼠移到物品上按查價熱鍵。程式會替你送出複製鍵：PoE1 是 `Ctrl + C`，PoE2 是 `Ctrl + Alt + C`（進階複製才拿得到褻瀆詞綴的 Tier）。
2. 面板會列出詞綴篩選，勾選要納入搜尋的詞綴、調整數值範圍。預設容差在「設定 › 查價」。
3. 傳奇和通貨會直接開始查；其他物品調好篩選後按「搜尋」。
4. 想看完整結果，按「交易」會用瀏覽器開交易站的同一個搜尋。

也可以手動貼上：面板沒有物品時，把遊戲裡複製的物品文字貼進去按「解析」。

查價出錯時按面板下方的「回報這件」，程式會整理成 GitHub issue 草稿。不會自動送出，也不含帳號名，由你確認後自己送。

![設定 › 熱鍵與視窗](/images/guides/exile-appraiser/settings-hotkeys.png)

*熱鍵、OCR 狀態與辨識區域都在「熱鍵與視窗」分頁。*

## 靈魂之井三選一辨識（PoE2）

靈魂之井的揭露面板沒辦法複製文字，所以改用 Windows 內建的文字辨識（OCR）讀畫面。辨識在本機執行，截圖不存檔也不上傳。

要先裝 Windows 的 OCR 語言包（只需要一次）：

1. Windows 設定 → 時間與語言 → 語言與地區。
2. 在「中文(台灣)」點「⋯ → 語言選項」；英文客戶端改選「英文(美國)」。清單裡沒有就先新增語言。
3. 在「光學字元辨識」按下載。
4. 回到程式的「設定 › 熱鍵與視窗」，「OCR 狀態」顯示「可用」就好了。

之後打開靈魂之井三選一畫面，每個選項右邊會出現「Tier · 詞綴池 · 數值範圍」的標記。`Ctrl + Shift + R` 可以暫停或繼續自動辨識。

標記出現「?」代表最近 10 分鐘內沒查過這件物品的價，程式不知道底材，只能用三個選項共同可能的底材推算。先對物品查一次價再開面板，結果會比較準。

![靈魂之井辨識標記](/images/guides/exile-appraiser/well-of-souls-ocr.png)

*每個選項右側標出詞綴 Tier、詞綴池與數值範圍。*

辨識不穩時，可以在「設定 › 熱鍵與視窗」按「在遊戲上框選」，把揭露面板框起來，`Enter` 確認。之後辨識會先只看那一塊，比較快也比較準。

## 符文塑形自動查價（PoE2）

在「設定 › 熱鍵與視窗」勾「啟用符文塑形自動查價」（預設關閉）。開著符文塑形面板時，程式會定時辨識面板，在每一列右邊標出 poe.ninja 參考價。只截圖加本機 OCR，不會送任何按鍵。

- 以崇高石計價，滿 1 神聖石改用神聖石；總價高於門檻顯示金色，低於門檻顯示暗色，門檻可以在設定裡改。
- poe.ninja 沒有價格的列（例如技能寶石）會自動排隊查交易站，顯示成「市 …」。為了不影響平常查價，交易站額度不夠時會自動延後。
- 台服沒有 poe.ninja 價格，全部改查台服交易站，以掛單原幣顯示。

![符文塑形自動查價](/images/guides/exile-appraiser/runeshape-prices.png)

*每一列右側標出參考價，查交易站的結果會另外標「市」。*

## 其他工具

- **Poe Regex 搜尋字串產生器**（設定 › 正則）：選遊戲和清單，勾選想找的詞綴或名稱，按「複製」貼進遊戲的倉庫或商店搜尋列。可以合併多頁勾選、存書籤、用分享碼給別人，也有內建範本，例如 T17 危險詞綴、地圖無反射。輸出語言要和遊戲客戶端一致。
- **拆粉排行**（PoE1）：查傳奇時面板會顯示能拆出多少粉塵。「拆粉排行」分頁列出所有傳奇，可以依「粉塵 / c」「粉塵 / gold」等方式排序。價格來自 poe.ninja，只有國際服。
- **聊天指令與倉庫搜尋**（設定 › 聊天指令）：預設 `F5` 是 `/hideout`、`F9` 是 `/exit`，`@last ty` 之類也能自己設熱鍵；倉庫搜尋熱鍵會把字串輸入倉庫搜尋框。
- **瀏覽器預覽設定**：系統匣選單的「在瀏覽器開啟設定」可以用一般瀏覽器看、改設定，只在本機開得起來。

![拆粉排行](/images/guides/exile-appraiser/dust-ranking.png)

*拆粉排行可以依粉塵效率排序，每列都能直接開交易站或 poe.ninja。*

## 常見問題

### 按熱鍵沒反應，overlay 沒出現在遊戲上

遊戲請用無邊框視窗或視窗模式，全螢幕獨占模式下 overlay 可能蓋不上去，OCR 也可能抓到黑畫面。再確認「設定 › 熱鍵與視窗」裡的遊戲視窗標題和實際的一致（預設 `Path of Exile` / `Path of Exile 2`）。熱鍵被其他程式佔用時設定頁會提示，換一組就好。不想用 overlay 的話，可以取消「疊加在遊戲上」改用獨立視窗。

### 聯盟清單載不出來，或出現驗證頁

交易站前面有 Cloudflare 防護。到「設定 › 一般」按「開啟交易站(解除驗證)」，完成一次驗證後按「重試」。顯示「限流中」是交易站的查詢頻率限制，倒數結束後會自動重試。

### OCR 認不出來或找不到面板

先確認「OCR 狀態」是「可用」，缺語言包就照上面的步驟裝。遊戲 UI 太暗會影響辨識；用框選把範圍縮到面板上通常比較準，換解析度或 UI 縮放後要重新框選。「辨識語言」要和遊戲畫面實際的語言一致。

### 台服和國際服有什麼不同

台服查 `pathofexile.tw`，目前只支援繁體中文客戶端。poe.ninja 沒有台服價格，所以台服沒有拆粉價格，符文塑形改查台服交易站。

### 設定和記錄存在哪裡

設定在 `%APPDATA%\exile-appraiser\config.json`，系統匣選單的「開啟設定資料夾」可以直接打開。程式記錄只存在本機，保留 7 天，不會自動上傳；回報問題時可以到「設定 › 記錄」篩選錯誤後複製貼上。
