## 這個版本能幫你做什麼

如果你用國際服的繁中客戶端，又想用 [Awakened PoE Trade](https://github.com/SnosMe/awakened-poe-trade) 查價，應該會發現很多物品複製出來它看不懂。Awakened PoE Trade-zh-TW 就是修這件事的繁體中文修正版。

查價、overlay、快捷鍵跟交易資料來源都是原作的，我改的地方主要是讓繁中客戶端複製出來的物品文字能正確解析，還有修好海圖區域跟傭兵流派送到交易站時用錯欄位的問題。

先講清楚：這是非官方的第三方程式，Grinding Gear Games 不保證任何第三方工具現在或以後都被允許，帳號風險要你自己評估。

## 安裝前要準備的東西

- Windows 10 或 11。
- Path of Exile 國際服 PC 客戶端，語言設成繁體中文。
- 從 [Awakened PoE Trade-zh-TW Releases](https://github.com/Hsiung-Shao/awakened-poe-trade-zh-TW/releases/latest) 下載安裝版或免安裝版。
- 如果你電腦裡已經有官方版，可以換著用，但兩個不要同時開。

安裝版跟官方版的安裝位置、解除安裝項目是分開的，但設定都放在 `%APPDATA%\awakened-poe-trade`。所以你原本的聯盟、熱鍵跟登入狀態通常會直接沿用；反過來說，在這邊改的設定也會影響之後開的另一個版本。

## 使用方式：下載、驗證跟安裝

1. 在 Release 頁選安裝版 `Awakened-PoE-Trade-zh-TW-Setup-<版本>.exe`，或免安裝版。
2. 同一個版本的 `SHA256SUMS-<版本>.txt` 也一起下載。
3. 在下載資料夾打開 PowerShell，算一下檔案的雜湊：

```powershell
Get-FileHash .\Awakened-PoE-Trade-zh-TW-Setup-<版本>.exe -Algorithm SHA256
```

4. 跟 `SHA256SUMS` 對一下，不一樣就把檔案刪掉，不要執行。
5. 安裝檔沒有數位簽章，SmartScreen 跳提示的時候，確定來源跟雜湊都沒問題，再選「更多資訊 → 仍要執行」。
6. 裝完打開程式，它會待在 Windows 通知區背景執行。

SHA-256 只能確認你下載的檔案跟 Release 公告的一樣，沒辦法證明發布者的帳號沒有被盜。

## 第一次設定

1. 開 Path of Exile，等工具抓到遊戲視窗。預設的視窗標題是 `Path of Exile`。
2. 在遊戲裡按 `Shift + Space` 打開 overlay。
3. 點齒輪進設定。
4. 在「一般」確認語言是繁體中文、伺服器是國際服，然後選你現在玩的聯盟。
5. 看一下「PoE 記錄檔」跟「PoE 設定檔」的路徑。要用聊天通知、倉庫頁籤捲動這些功能的話，路徑一定要對。
6. 到「快捷鍵」確認查價跟 overlay 的按鍵沒有跟遊戲或其他程式撞到。

overlay 預設是 `Shift + Space`。查價快捷鍵可能會沿用你以前的設定，每台電腦不一定一樣，以設定頁「查價 → 自動隱藏模式」顯示的組合為準。

## 查價一件物品

1. 讓遊戲視窗保持在前景。
2. 滑鼠移到背包或倉庫裡的物品上，不用先點它。
3. 按設定頁顯示的查價快捷鍵。工具會幫你送一次複製，讀剪貼簿的文字然後打開查價視窗。
4. 確認最上面的物品名稱、底材、物品等級跟聯盟都對。
5. 傳奇通常用名稱查就好；稀有裝備要勾真正會影響價格的詞綴，不要每個數值都設成精確條件。
6. 調整最小／最大值、物品等級、已汙染、上架時間、在線狀態跟通貨這些條件。
7. 看結果數量、價格分布、賣家跟上架時間。結果太少就一點一點放寬詞綴數值，不要一次把條件全拿掉。
8. 想看完整的官方搜尋，用查價視窗的「交易」或瀏覽器入口打開交易站。

稀有物品本來就沒有唯一正確的價格。工具只能幫你建搜尋、比較掛單，實際能賣多少還是看詞綴組合、數值、聯盟的供需跟上架時間。

## 繁中客戶端特別處理的地方

繁中客戶端複製出來的文字有一些眉角：分隔線長度不固定、全形冒號、魔法物品名沒有空格、多出來的空行，還有詞綴標籤的格式不太一樣。修正版會先把這些整理好，再交給原本的解析流程。

查海圖區域或傭兵契約書的時候，記得確認查價視窗顯示的變體名稱對不對。交易站本身也有限制：不是每個海圖區域都能搜，傭兵等級也沒辦法當官方交易站的篩選條件。

## 怎麼調查價條件比較準

- 傳奇：先確認變體、有沒有汙染、插槽對不對；未鑑定的可能要你手動選是哪一件傳奇。
- 稀有裝備：只勾核心詞綴就好，元素抗性這種同類的可以用偽屬性合併。
- 武器：看物理 DPS、元素 DPS、攻速跟暴擊哪個才是重點。
- 寶石：確認等級、品質跟特殊版本。
- 地圖：確認階級、區域、汙染跟危險詞綴。
- 大宗物品：要看庫存跟能成交的數量，不要只看最便宜的那一筆。

「自動填入屬性數值」會把物品現在的數字直接帶進條件，如果又勾精確值，搜尋很容易太窄。一般估價先留一點誤差，再慢慢縮小。

## Overlay 跟其他功能

- `Shift + Space`：預設切換可以操作的 overlay，可以移動或設定元件。
- 物品資訊：可以直接開 Wiki、PoEDB 或 Craft of Exile 對應的頁面。
- 地圖檢查：依你的設定檔標出危險的地圖詞綴。
- 倉庫搜尋：幫你把搜尋文字送進去，在倉庫頁找東西比較快。
- 碼錶、圖片列這些元件：從 overlay 的元件選單加。

快捷鍵重複的話，程式會拒絕註冊其中一個。如果按了完全沒反應，先到設定改成沒被遊戲、錄影軟體或其他 overlay 佔用的組合。

## 想降低風險：把聊天指令熱鍵關掉

預設設定裡有兩個會把一整串按鍵送進遊戲的聊天指令：

- `F5`：`/hideout`
- `F9`：`/exit`

這種功能按一次就會做完 Enter、貼上文字、再 Enter，比單一個遊戲動作還多，是整套工具裡風險最高的部分。查價根本用不到它們。想降低風險的話：

1. 打開「設定 → Chat／聊天」。
2. 選 `/hideout` 跟 `/exit` 的快捷鍵欄位。
3. 按 Backspace 清掉綁定。
4. 存檔並重開工具，確認 F5、F9 不會再觸發聊天指令。

工具還是會讀剪貼簿、送 `Ctrl + C`、顯示 overlay，也會讀 `Client.txt` 跟 `production_Config.ini`；它不讀遊戲記憶體、不注入 DLL、不改遊戲檔案，也不攔網路封包。

## 更新

程式開啟的時候跟之後每 16 小時只會檢查有沒有新版，不會自己下載。

1. 打開「設定 → 關於」。
2. 有新版的話會顯示版本跟「Install now／立即安裝」。
3. 你按下去才會開始下載，下載完會提示你在關掉程式的時候安裝。
4. 想先自己對 SHA-256，可以按「開啟下載頁面」手動下載驗證。
5. 免安裝版沒辦法直接更新，會帶你到下載頁。

用 `--no-updates` 啟動的話，連檢查都不會做。

## 常見問題

### 按查價鍵完全沒反應

確認程式有在通知區跑、遊戲視窗標題跟設定一樣，再看快捷鍵有沒有衝突。如果遊戲是用系統管理員身分開的，工具卻不是，也可能送不出按鍵。

### 顯示解析錯誤

先確認你用的是繁中修正版的最新版。在遊戲裡重新按一次 `Ctrl + C`，把完整的物品文字留下來；回報的時候附上物品文字、遊戲版本跟工具版本，只附一張空白的錯誤視窗我會看不出問題在哪。

### 聯盟或交易資料載不出來

伺服器維護、Cloudflare 驗證或舊版 User-Agent 都有可能。先更新程式，再按錯誤畫面的「瀏覽器」把可能的驗證過掉；不要一直狂按重試。

### 切回官方版之後設定怪怪的

兩個版本共用 `%APPDATA%\awakened-poe-trade`。先把兩個都關掉、備份這個資料夾，再決定要不要重設。不要讓兩個版本同時寫入。
