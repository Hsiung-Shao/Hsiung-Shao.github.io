## 這個版本和原版有什麼不同

Awakened PoE Trade-zh-TW 是 [Awakened PoE Trade](https://github.com/SnosMe/awakened-poe-trade) 的繁體中文修正版。核心查價、overlay、快捷鍵與交易資料來源均沿用原作，修改重點是讓國際服繁中客戶端複製出的物品文字能正確解析，並修正海圖區域與傭兵流派送到交易站時使用錯誤欄位的問題。

本工具是非官方第三方程式。Grinding Gear Games 不保證任何第三方工具現在或未來被允許，使用者需要自行評估帳號風險。

## 安裝前準備

- Windows 10 或 Windows 11。
- Path of Exile 國際服 PC 客戶端，語言使用繁體中文。
- 從 [Awakened PoE Trade-zh-TW Releases](https://github.com/Hsiung-Shao/awakened-poe-trade-zh-TW/releases/latest) 下載安裝版或免安裝版。
- 若電腦已有官方版，可以切換使用，但兩個版本不要同時執行。

安裝版與官方版安裝目錄、解除安裝項目分開，但都使用 `%APPDATA%\awakened-poe-trade`。因此原有聯盟、熱鍵與登入狀態通常會沿用；這也代表修改設定會同時影響之後啟動的另一版本。

## 使用方式：下載、驗證與安裝

1. 在 Release 頁選擇安裝版 `Awakened-PoE-Trade-zh-TW-Setup-<版本>.exe`，或免安裝版本。
2. 同時下載該版本的 `SHA256SUMS-<版本>.txt`。
3. 在下載資料夾開啟 PowerShell，計算檔案雜湊：

```powershell
Get-FileHash .\Awakened-PoE-Trade-zh-TW-Setup-<版本>.exe -Algorithm SHA256
```

4. 把結果和 `SHA256SUMS` 對照；不同就刪除檔案，不要執行。
5. 安裝檔沒有數位簽章。SmartScreen 出現提示時，只有在來源與雜湊都確認後，再選「更多資訊 → 仍要執行」。
6. 完成安裝並啟動程式。它會留在 Windows 通知區背景執行。

SHA-256 能確認下載檔和 Release 公告一致，但不能證明發布者帳號本身沒有遭入侵。

## 第一次設定

1. 啟動 Path of Exile，等待工具偵測到遊戲視窗。預設視窗標題是 `Path of Exile`。
2. 在遊戲內按 `Shift + Space` 開啟 overlay。
3. 點齒輪進入設定。
4. 在「一般」確認語言為繁體中文、伺服器為國際服，並選擇目前聯盟。
5. 檢查「PoE 記錄檔」與「PoE 設定檔」路徑。需要聊天通知、倉庫頁籤捲動等功能時，路徑必須正確。
6. 到「快捷鍵」確認查價與 overlay 按鍵沒有和遊戲或其他程式衝突。

預設 overlay 鍵是 `Shift + Space`。查價快捷鍵的實際值可能沿用既有設定，因此文章不假設每台電腦都相同；請以設定頁「查價 → 自動隱藏模式」顯示的組合為準。

## 查價一件物品

1. 讓 Path of Exile 遊戲視窗保持前景。
2. 把滑鼠移到背包或倉庫中的物品上，不必先點擊物品。
3. 按設定頁顯示的查價快捷鍵。工具會送出一次複製動作，讀取剪貼簿文字並打開查價視窗。
4. 確認最上方的物品名稱、底材、物品等級與聯盟正確。
5. 傳奇物品通常以名稱查價；稀有裝備應勾選真正影響價格的詞綴，避免把所有數值都設為精確條件。
6. 調整最小／最大值、物品等級、已汙染、上架時間、在線狀態與通貨等條件。
7. 查看結果數量、價格分布、賣家與上架時間。結果太少時逐步放寬詞綴數值，不要一次移除所有條件。
8. 需要完整官方查詢時，使用查價視窗的「交易」或瀏覽器入口開啟交易站。

稀有物品沒有唯一正確價格。工具只能協助建立搜尋與比較掛單；實際成交價仍取決於詞綴組合、數值、聯盟供需與上架時間。

## 繁中修正版特別處理的物品

繁中客戶端可能使用不固定長度分隔線、全形冒號、沒有空格的魔法物品名、額外空行或不同詞綴標籤格式。修正版會先正規化這些格式，再交給原本解析流程。

查價海圖區域或傭兵契約書時，請確認查價視窗顯示的變體名稱正確。交易站本身仍有限制：不是每個海圖區域都可搜尋，傭兵等級也無法作為官方交易站篩選條件。

## 調整查價條件

- 傳奇物品：先確認是否為正確變體、汙染狀態與插槽；未鑑定物品可能需要手動選擇是哪一件傳奇。
- 稀有裝備：只勾選核心詞綴。可用偽屬性合併元素抗性等同類條件。
- 武器：檢查物理 DPS、元素 DPS、攻速與暴擊是否為評價重點。
- 寶石：確認寶石等級、品質與特殊版本。
- 地圖：確認階級、區域、汙染與危險詞綴。
- 大宗物品：查看庫存與可成交數量，不要只看單價最低的一筆。

「自動填入屬性數值」會把物品目前數字帶入條件；若勾選精確值，搜尋很容易過窄。一般估價先保留合理誤差，再逐步縮小。

## Overlay 與其他功能

- `Shift + Space`：預設切換可互動 overlay，可移動或設定元件。
- 物品資訊：可開啟 Wiki、PoEDB 或 Craft of Exile 對應頁。
- 地圖檢查：依設定檔標示危險地圖詞綴。
- 倉庫搜尋：送出搜尋文字，協助在倉庫頁找項目。
- 碼錶、圖片列與其他元件：可從 overlay 的元件選單加入。

快捷鍵重複時，程式會拒絕註冊其中一個。若按鍵完全沒有反應，先到設定改用未被遊戲、錄影軟體或其他 overlay 佔用的組合。

## 降低風險：關閉聊天指令熱鍵

預設設定含兩個會把完整按鍵序列送進遊戲的聊天指令：

- `F5`：`/hideout`
- `F9`：`/exit`

這類功能一次按鍵會完成 Enter、貼上文字、再 Enter，多於單一遊戲動作，是整套工具中風險最高的路徑。查價不需要它們。要降低風險：

1. 開啟「設定 → Chat／聊天」。
2. 選取 `/hideout` 與 `/exit` 的快捷鍵欄位。
3. 按 Backspace 清除綁定。
4. 儲存設定並重啟工具，確認 F5、F9 不再觸發聊天指令。

本工具仍會讀取剪貼簿、送出 `Ctrl + C`、顯示 overlay，並可讀取 `Client.txt` 與 `production_Config.ini`；它不讀取遊戲記憶體、不注入 DLL、不修改遊戲檔案，也不攔截網路封包。

## 更新方式

程式啟動時及每 16 小時只檢查是否有新版，不會自行下載。

1. 開啟「設定 → 關於」。
2. 有新版時會顯示版本與「Install now／立即安裝」。
3. 按下後才開始下載；下載完成會提示在程式關閉時安裝。
4. 想先自行核對 SHA-256，可按「開啟下載頁面」，手動下載並驗證。
5. 免安裝版無法就地更新，會直接引導到下載頁。

使用 `--no-updates` 啟動可連檢查都關閉。

## 常見問題

### 按查價鍵完全沒反應

確認程式在通知區執行、遊戲視窗標題符合設定，並檢查快捷鍵是否衝突。以系統管理員執行遊戲但工具不是相同權限時，也可能無法送出按鍵。

### 顯示解析錯誤

先確認使用的是繁中修正版最新版本。重新在遊戲內按 `Ctrl + C`，把完整物品文字保留下來；回報時附物品文字、遊戲版本與工具版本，不要只附空白錯誤視窗。

### 無法載入聯盟或交易資料

伺服器維護、Cloudflare 驗證或舊版 User-Agent 都可能造成。先更新程式，再按錯誤畫面的「瀏覽器」完成可能的 CAPTCHA；不要反覆高速重試。

### 切回官方版後設定怪異

兩版共用 `%APPDATA%\awakened-poe-trade`。先關閉兩版，備份該資料夾，再決定是否重設設定。不要讓兩個版本同時寫入。
