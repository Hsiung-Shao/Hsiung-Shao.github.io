## 這個工具解決什麼問題

MultiStream Hub 是免註冊的 Twitch／YouTube 多直播觀看工具。它不是單純把幾個播放器排成網格，而是提供一個可拖曳、縮放與保存的畫布：串流和聊天室可以各自成為視窗，也能使用預設布局快速排列。

收藏、分類、標籤、布局與偏好主要儲存在目前瀏覽器的本機空間。換瀏覽器、清除網站資料或更換裝置前，應先匯出 JSON 備份。

## 開始前準備

- 使用最新版 Chrome、Edge、Firefox 或 Safari。
- Twitch 可直接用頻道名稱搜尋；YouTube 建議準備直播影片的完整網址，例如 `https://www.youtube.com/watch?v=VIDEO_ID`。
- YouTube 頻道名稱搜尋只查詢本站已收錄的頻道，不是搜尋整個 YouTube；搜尋結果通常先加入收藏，開台後再載入。
- 同時播放越多直播，CPU、記憶體與網路用量越高。效能不足時先降低同時播放數量或個別畫質。

## 使用方式：建立第一個多直播畫布

1. 開啟 [MultiStream Hub](https://multistreaming.org/)，進入「畫布」。
2. 點畫面上方動態島的搜尋框。
3. Twitch 可輸入實況主名稱，從即時搜尋結果按 `+` 加入；也可以直接貼上 Twitch 或 YouTube 直播網址。
4. 重複加入其他頻道。每個來源會建立自己的串流視窗。
5. 開啟「布局設定」，選擇適合目前視窗數量的預設布局；需要自己安排時，直接拖曳視窗標題列移動位置，拖曳四角調整大小。

![MultiStream Hub 的動態島搜尋框](/images/guides/multistream/island-search-bar.webp)

*搜尋框可辨識直播網址，也可搜尋 Twitch 與站內已收錄的 YouTube 頻道。*

若目前沒有可直接播放的頻道，也可以先按動態島的 `+`：

- 「新增組合」：一次建立串流與聊天室兩個空視窗。
- 「新增串流視窗」：只建立播放器。
- 「新增聊天室視窗」：只建立聊天室，適合監看聊天。

空視窗建立後，從「正在直播的收藏」選擇頻道即可載入。

![新增串流與聊天室組合](/images/guides/multistream/add-window-combo.webp)

*「新增組合」適合希望畫面與聊天室並排的使用者。*

## 調整布局與視窗

自動布局適合快速整理；自訂布局適合固定的賽事、多視角或聯動組合。

1. 按住視窗上方標題列拖曳。
2. 從視窗四角拖曳縮放，避免只拉單邊造成比例不符預期。
3. 每個視窗標題列可獨立靜音、調整音量、重新整理、收合或關閉。
4. 開啟「媒體控制」可一次調整主音量或全部靜音；個別音量仍保留相對比例。
5. 排好後開啟布局選單，切到「自定義清單」，按「儲存目前布局」並命名。也可使用動態島的一鍵儲存按鈕。
6. 之後到「收藏管理 → 布局管理」套用、預覽或刪除保存的布局。

![拖曳與縮放視窗](/images/guides/multistream/window-drag-resize.webp)

*綠色區域是拖曳把手，四角是縮放熱區。*

## 聊天室怎麼安排

一般布局可讓聊天室跟著串流視窗顯示或隱藏；需要長時間監看時，可改用側邊聊天布局：

- 單一聊天室：主要影片在左、固定聊天室在右。
- 雙欄聊天：右側固定兩個聊天室。
- 四格聊天：右側以 `2 × 2` 顯示四個聊天室。

聊天室選擇器可更換右側顯示的頻道，不必重排串流順序。若 Twitch 聊天室空白，先確認瀏覽器沒有封鎖第三方 Cookie、追蹤內容或嵌入式框架；Brave 的 Shields 也可能阻擋聊天室。

## 建立收藏、分類與標籤

1. 開啟「收藏管理」。
2. 按「新增收藏」，貼上 Twitch／YouTube 網址或輸入頻道名稱。
3. 確認平台與顯示名稱，可指定分類並加入多個標籤。
4. 想立即觀看可勾選「新增後立即載入畫面」。
5. 回到畫布，按星號開啟「收藏直播」面板。
6. 使用「僅顯示直播中」、分類與多標籤縮小清單，再勾選一個或多個頻道載入。

Twitch 使用者也可在收藏管理內連結帳號，匯入已追隨頻道。這項操作用於建立本機收藏，網站本身不要求註冊 MultiStream Hub 帳號。

![收藏管理畫面](/images/guides/multistream/favorites-manager.webp)

*頻道、分類、標籤、Twitch 匯入與布局都集中在收藏管理。*

## 備份與搬到另一台裝置

1. 開啟「設定」或「收藏管理 → 設定」。
2. 在資料管理區按「匯出」，下載 JSON 備份。
3. 到另一個瀏覽器或裝置開啟同一頁面。
4. 按「匯入」並選擇剛才的 JSON。
5. 檢查收藏、分類、標籤與布局是否完整後，再刪除舊裝置資料。

![MultiStream Hub 設定面板](/images/guides/multistream/settings-panel.webp)

*清除瀏覽器網站資料前，先在資料管理區匯出備份。*

## 常見問題

### YouTube 網址加入後不能播放

優先使用實際直播影片的 `watch?v=` 網址。頻道 `/live` 網址需要先確認目前是否開台，較適合透過收藏清單載入。

### YouTube 搜尋不到頻道

YouTube 名稱搜尋只比對本站資料庫。可改貼完整直播網址；若希望將頻道加入資料庫，可透過網站的回報管道提出。

### 畫面有聲音但聊天室空白

重新整理該聊天室視窗，並檢查瀏覽器的第三方 Cookie、內容阻擋與隱私擴充功能。播放器與聊天室都是 Twitch／YouTube 官方嵌入內容，封鎖規則可能不同。

### 同時播放時很卡

先把非主要台靜音並降低其畫質，關閉暫時不看的聊天室或串流。大量高畫質直播同時解碼仍受電腦與網路能力限制。

## 資料與隱私

網站以本機儲存保存收藏與設定；清除瀏覽器網站資料會一併移除。播放器與聊天室則由 Twitch／YouTube 提供，仍受各平台的 Cookie、登入與隱私政策影響。
